# 🛠 Personalized Wordlist Generator

🚀 A **CLI-based tool** for Kali Linux that generates **custom password wordlists** based on user-provided information like name, date of birth, city, and favorite animal.  
🔒 Helps in **targeted password cracking** and penetration testing by creating more relevant and effective wordlists.

---

## 🎯 **Features**
✅ **Interactive CLI** - User-friendly Metasploit-style interface with colors and ASCII art.  
✅ **Smart Wordlist Generation** - Creates passwords **linked to user input** (not just random numbers).  
✅ **Special Character Substitutions** - Converts letters to symbols (`a → @`, `s → $`, `i → !`, etc.).  
✅ **Creative Combinations** - Generates passwords like `Rajesh@69`, `Rahul$69`, `T!g3r6969`, etc.  
✅ **Customizable** - Users can set **maximum password length** and **output file names**.
